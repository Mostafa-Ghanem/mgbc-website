# MGBC Website

موقع عربي RTL جديد لشركة **MG Business Consultancy**، مبني كصفحة ثابتة سريعة ومتجاوبة، ومستوحى في تجربة الاستخدام من أسلوب Plax Home 2 مع هوية MGBC الكحلية والذهبية.

## المزايا

- تصميم عربي RTL متجاوب بالكامل.
- تحسينات SEO وبيانات منظمة Schema.org.
- أداء مرتفع دون أطر عمل أو مكتبات JavaScript ثقيلة.
- قائمة جوال، FAQ تفاعلي، عدادات، وحركات ظهور تراعي `prefers-reduced-motion`.
- قابل للنشر مباشرة عبر GitHub Pages.

## التشغيل محلياً

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الملفات

- `index.html` الصفحة الرئيسية.
- `styles.css` نظام التصميم والتجاوب.
- `script.js` التفاعلات الخفيفة.
- `assets/` الشعار وصورة المشاركة.
