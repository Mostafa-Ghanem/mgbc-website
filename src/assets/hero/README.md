# Hero photograph

Place one licensed photo here named `riyadh-skyline.jpg` (or `.webp`/`.png`).
`HeroDecision.astro` picks it up automatically; without it the hero renders the plain navy composition.

- Subject: Riyadh skyline (e.g. KAFD / Kingdom Centre), dusk or blue hour.
- Minimum 2400px wide, landscape; key buildings in the left half of the frame.
- Astro converts it to WebP at 800/1280/1920px. Commit the original only.
- Record the licence/source in this file when adding the photo.
