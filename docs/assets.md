## Image strategy
- Do not use stock photography in the hero; the MGBC mark and typography own the first viewport.
- Use images only when they add context, evidence, or editorial relief.
- Prefer one strong image over repeated generic office/handshake photography.
- All images require useful alt text, explicit dimensions, lazy loading below the fold, and a stable aspect ratio.
